# KZSC v0.11.2.35-generic

## Türkçe

- Cihazlar tablosundaki WAN DPI Profili sütunu kaldırıldı.
- Keenetic IP rezervasyonu alanı daha kompakt bir düzende gösterilir.
- Cihaz satırları daha az dikey alan kullanır ve tek ekranda daha fazla cihaz gösterir.

## English

- Removed the WAN DPI Profile column from the Devices table.
- Made the Keenetic IP reservation controls more compact.
- Device rows use less vertical space so more devices fit on one screen.
