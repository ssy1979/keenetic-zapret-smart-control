# KZSC v0.11.2.59-generic

## Türkçe

- Manuel kaydedilmiş ve motoru aktif DPI profili artık Blockcheck tarafından doğrudan korunur.
- Blockcheck, isteğe bağlı ayrıntılı veri yolu denetimi nedeniyle çalışan profilin gereksiz uzun taramaya düşmesine izin vermez.
- Motor kapalıysa normal profil doğrulaması ve Blockcheck taraması devam eder.

## English

- A manually saved DPI profile with an active engine is now retained immediately by Blockcheck.
- An optional strict datapath diagnostic can no longer send a working profile into an unnecessary long scan.
- When the engine is stopped, normal profile validation and Blockcheck scanning continue.
