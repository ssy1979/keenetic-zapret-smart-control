# KZSC v0.11.2.64-generic

## Türkçe
- Otomatik DPI çalışma modu kaldırıldı; kararlı Tüm Ağ politikası korundu.
- Çalışma Modu sekmesi Alan Adı Politikası olarak yeniden adlandırıldı.
- Zapret dışında tutulacak alan adı/uzantı listeleri korunmuştur.
- Üst bildirimler yalnızca son üç kaydı gösterir.
- Ayarlar sekmesine kalıcı İşlem Geçmişi eklendi.
- Superonline profil doğrulaması öncesi motor yeniden başlatma ve NFQUEUE stabilizasyonu iyileştirildi.

## English
- Automatic DPI operating mode was removed; the stable All Network policy remains.
- The Operating Mode tab is now Domain Policy.
- Zapret exclusion domain/suffix lists are preserved.
- Only the latest three top notifications are retained.
- Settings now includes persistent Operation History.
- Saved-profile probing now restarts and settles NFQUEUE before validation.
