# KZSC v0.11.2.34-generic

## Türkçe

- WAN DPI profil seçimleri periyodik durum yenilemesinde korunur.
- Profil yalnızca “Profili Kaydet” ile uygulanır; kaydedilmemiş seçim geri döndürülmez.

## English

- WAN DPI profile selections persist across periodic status refreshes.
- A profile is applied only by “Save Profile”; unsaved selections are not reverted.
