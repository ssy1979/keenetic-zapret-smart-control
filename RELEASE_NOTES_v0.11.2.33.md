# KZSC v0.11.2.33-generic

## Türkçe

- Cihazlar ekranında genişleticiler gizlenir; yalnızca istemci cihazları gösterilir.
- WAN DPI profili seçimi artık yalnızca “Profili Kaydet” düğmesine basıldığında uygulanır; açılır liste seçimi korunur.
- Çalışan eski KZSC Superonline profili `Superonline Fiber` adıyla geri getirildi ve Blockcheck preset-first akışına dahil edildi.
- Blockcheck test hedefi alanı yenileme sırasında korunur; kullanıcı yazarken varsayılan hedefe dönmez.
- DPI / Blockcheck ve güncelleme regresyon kontrolleri yenilendi.

## English

- Extenders are hidden from the Devices screen; only client devices are listed.
- WAN DPI profile selection is applied only by “Save Profile”; dropdown changes are preserved.
- The working legacy KZSC Superonline profile is restored as `Superonline Fiber` and included in preset-first Blockcheck.
- Blockcheck target input is preserved across refreshes instead of reverting to the default target.
- DPI / Blockcheck and updater regression checks were refreshed.
