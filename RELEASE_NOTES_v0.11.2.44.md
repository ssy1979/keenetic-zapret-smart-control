# KZSC v0.11.2.44-generic

## Türkçe

- Cihazlar ekranındaki IP rezervasyonu alanı kaldırıldı; statik IP yönetimi Keenetic arayüzüne bırakıldı.
- Cihazların internet çıkışında kullanılan DPI profili gösteriliyor.
- Çalışma Modu alan adı listelerine virgülle ayrılmış birden fazla alan adı tek seferde eklenebiliyor.
- Türkçe ve İngilizce arayüz metinleri güncellendi.

## English

- Removed IP reservation controls from Devices; static IP assignment is managed in the Keenetic interface.
- The DPI profile used by each device's Internet exit is now shown.
- Operating Mode lists accept multiple comma-separated domains in one action.
- Updated Turkish and English interface text.
