Güvenli DNS

Keenetic DNS proxy üzerinden DoT veya DoH kullan. İstersen aktif internet bağlantılarında ISS tarafından verilen DNS sunucularını yok say.
Yükleniyor…
Not: Normal Uygula mevcut elle eklenmiş güvenli DNS kayıtlarını korur. Temiz Kurulum seçilirse mevcut manuel DNS, DoT ve DoH kayıtları silinir ve seçilen sağlayıcı sıfırdan kurulur. İşlem öncesi KZSC DNS snapshot oluşturur. DoT/DoH için ilgili KeeneticOS DNS proxy bileşeninin kurulu olması gerekir.

Telegram Bildirim Botu

KZSC olaylarını Telegram botu üzerinden gönder. Bot Token gizli saklanır ve arayüzde geri gösterilmez.
Chat ID Bul için önce Bot Token'ı kaydet, Telegram'da bota /start gönder, sonra butona bas. Telegram ile yönetim açılırsa yalnız kayıtlı Chat ID komut verebilir. /help ile komutları görebilirsin.
