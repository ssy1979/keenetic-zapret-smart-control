# KZSC v0.11.2.37-generic

## Türkçe

- Zapret2 IPv6 desteği Türkçe ve İngilizce arayüzde açıkça çevrildi.
- Zapret2 sekmesine güvenli, salt-okunur yeni sürüm kontrolü eklendi.
- Zapret2 güncel sürümü ve kullanılabilir güncelleme bilgisi arayüzden görülebilir.
- IPv6 runtime doğrulaması ve geri alma davranışı korunarak doğrulandı.

## English

- Zapret2 IPv6 support is now clearly translated in both Turkish and English UI.
- Added a safe read-only Zapret2 version check to the Zapret2 tab.
- The UI can report the installed version and whether an update is available.
- IPv6 runtime validation and rollback behavior remain covered by regression tests.
