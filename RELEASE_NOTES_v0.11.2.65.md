# KZSC v0.11.2.65-generic

Blockcheck önce kısa preset doğrulamasını çalıştırır. Uyumlu profil bulunamazsa sabit süre sınırı olmadan tam upstream standard strateji setine geçer ve uygun sonucu bulduğunda otomatik kaydeder.

Blockcheck first runs the short preset validation. If no compatible profile is found, it continues without a wall-clock limit using the complete upstream standard strategy set and saves the first working result.
