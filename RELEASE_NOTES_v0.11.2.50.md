# KZSC v0.11.2.50-generic

## Türkçe

- Zapret2 durum JSON’unda kök dizin ve diğer metin alanları güvenli JSON kaçışından geçirilir.

## English

- Zapret2 status JSON now safely escapes the root path and all text fields.
- Special characters in automatic-update status can no longer corrupt the panel JSON.
